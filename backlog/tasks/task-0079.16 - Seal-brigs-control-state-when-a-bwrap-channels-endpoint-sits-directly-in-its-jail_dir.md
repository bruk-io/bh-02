## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-173 (TASK-0079.13) takes the jail_dir back out of any write root or channel directory above it, but states one residual: on bwrap a LISTEN endpoint whose directory IS the jail_dir makes the whole jail_dir writable (the endpoint directory is the smallest grant a bind mount can make for a socket), so the jail can still write execs/ registrations, the exit record and its logs there, and decision-172's forged-record residual stands for that arrangement. brig's own e2e strict journey (tests/e2e/test_strict_linux_journey.py, endpoint <jail_dir>/agent.sock) and SPEC §6's 'ordinary arrangement' use it; bh-02 does not (its endpoint is in /tmp/bh-k-*). Either refuse that layout on bwrap (ChannelInsideJailDir, naming both) or move brig's control files into a subdirectory the channel grant does not reach; TASK-0079.05's channel directory per jail may settle it.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Built in bruk-io/brig, on its own board; this task tracks what bh-02 needs and closes when a commit on that repository's main delivers it. TASK-0176.01 has the measurement.

bh-02 interrupts a running input by sending SIGINT to the program (`_Jailed.interrupt`, from the old brig's `Process.interrupt`); the worker turns it into KeyboardInterrupt in the input and keeps running. The new brig has no public call that signals the supervised command, and its supervisor (`infra/supervisor/program.py`) forwards SIGTERM only: SIGINT to the supervisor's group did not reach the program (TASK-0176.01).

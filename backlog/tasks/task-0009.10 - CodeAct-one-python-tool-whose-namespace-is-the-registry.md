## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
New member codeact-cordis-plugin: `codeact:python` binds `actions` = CodeAct(tools, kernel). specs() = [PYTHON] only; each cell runs in the kernel with `tools.specs()` read for that cell (so a tool registered mid-session is in the next cell; nothing reloads). Approval follows `kernel.confined`: confined → decide allows the cell, inner calls go through `tools.call` (guards); unconfined → decide asks the guards about the cell, inner calls use `tools.execute` (errors as text). Other tool names are refused with a pointer to the namespace. instructions() lists the namespace (each function returns a string; they run outside the jail and are checked) and where the code runs. bhh: `codeact.toml` (jail = brig:jail, kernel = kernel:kernel, actions = codeact:python) over a tools stack; `--codeact` (implies --tools) and `--no-jail` (override jail = kernel:unjailed). Composed tests in bhh/tests/test_codeact.py (unjailed: namespace persists, registry functions, NameError listing; darwin brig: project writable; outside, the patch layer, .git/hooks, network, ~/.ssh denied).

Design notes. (1) A sub-agent is a name in <session>/agents/ that matches the pattern bh-02 watch accepts (refused_agent); a call's child is only matched against those found, never made into a path. (2) --follow keeps no file offset: each poll re-reads every file and renders the whole trajectory, printing the Lines whose key (agent, conversation ident = its first at, position in the tree) was not printed, so a replaced file is new and a sub-agent printed before its call was recorded is not printed twice; a call whose result is not written yet is held back while following. (3) Row reloads: rows is parsed into Trajectory.reloads, not shown (TASK-0136.11 writes rows.jsonl, reads it and places the reloads; rows=b'' until then). (4) Generation time = took - first_chunk; tokens/s = output tokens / generation time (not shown for a partial usage). (5) The loop's feedback entries print as 'nudge' (the glossary word). (6) Budget: one new no-impure-functions entry, bh_02.cli:trajectory_command (it calls sessions.find, as sessions_command does); the viewing/trajectory functions are not charged. Also its over-exposed allow entry (click command).

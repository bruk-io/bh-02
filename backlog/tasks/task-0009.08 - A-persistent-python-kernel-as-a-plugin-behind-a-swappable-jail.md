## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
CodeAct needs a live namespace that survives turns and model swaps, can be interrupted without losing state, and runs where the operator's jail says. The jail is a key of its own so the layer file chooses it.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Variables persist across cells and across a model-row swap
- [x] #2 Interrupting a running cell stops it and keeps the namespace
- [x] #3 Calls to namespace tools go back through one channel to the host and are answered there
- [x] #4 An unjailed launcher exists and reports every axis as unenforced
- [x] #5 Retiring the kernel row ends its process
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
New member kernel-cordis-plugin. worker.py: stdlib-only program run by path (`python -I worker.py SOCKET`); newline-JSON over a Unix socket (hello, exec{code,tools}, call/return, done{output,error}); accepts until a connection speaks (a readiness probe connects and closes, found in the brig spike); cells on the main thread; SIGINT raises KeyboardInterrupt only while a cell runs; last expression shown notebook-style; tools bound as functions per cell (kwargs by schema names, positional in schema order), withdrawn tools removed; `list_tools()`; NameError lists callable names (harness's structured missing-name idea); output capped. client.py: `Kernel` async CM (starts the worker via the `jail` in a short /tmp dir, socket < 104 bytes), `run(code, tools, call) -> Cell`, cancellation → jail interrupt, drain until done within `grace` (answering calls with "interrupted"), else stop; a dead worker is restarted on the next cell with a note. `is_confined(report)` = fs_write and network enforced. unjailed.py: `kernel:unjailed` binds a jail that runs the worker in its own session and reports every axis unenforced. Rows: `kernel:kernel` (depends only on `jail`, so a model swap never touches it: AC1's second half is structural), `kernel:unjailed`. Gate: print-input exempts the worker module (its stdout is the cell's output), import-time-side-effects allows its `if __name__` guard, new `worker-stdlib-only` rule (verified with a planted `import cordis`), budget entries for the kernel's process/socket edges. 8 tests against a real worker process.

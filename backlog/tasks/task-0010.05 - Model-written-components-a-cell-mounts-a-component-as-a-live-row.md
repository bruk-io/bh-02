## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
What only cordis can do: the model writes a component (say, a tool plugin) and a cell asks for it to be mounted. It becomes a child of the codeact row: contract-checked, its registrations live, undone when it is replaced or the row leaves. It runs in bhh, outside the jail, so mounting is a guarded call.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 mount_component(name, source) mounts the component(s) the source defines, and a tool it registers is callable in the next cell
- [x] #2 Mounting under a name already mounted replaces the earlier one; unmount_component(name) retires it
- [x] #3 A source that fails (syntax, contract, setup) is reported back to the cell with cordis's diagnosis and leaves nothing installed
- [x] #4 Mounting passes the guards whether or not the kernel is jailed (it runs in the host)
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
codeact:python now yields a performer and registers `mount_component(name, source)` and `unmount_component(name)` into `tools` (so they are namespace functions). Mount: the source becomes a module registered in sys.modules *before* its code runs (the @component decorator records the module at decoration; found by a failing test), `scan` finds its components, each is `use`d as a child of the codeact fiber with id `name.component`; after they settle, any not ACTIVE is retired with the reason (failed: its error; never started: the keys it needs) and nothing stays installed; the same name again retires the earlier mount first (no AlreadyBound); the codeact row leaving undoes all. Mount/unmount are `guarded` in CodeAct: an approved unjailed cell's call to them still goes through tools.call (guards). Terminal: `confirm` prints a call's `source` whole before asking (a call from inside a cell has no event of its own), and renders a `source`/`code` argument as a block; the question says "run the code above in bhh, outside the jail". Gate: `_Mounts.*` on the purity budget; `_Mounts.mount` allowed in no-hidden-global-mutation (sys.modules, as cordis's scan requires); `sys.modules` added to terminal-io's not-terminal names. Tests: mounted tool callable; remount replaces; unmount; syntax / no component / setup raising / unbound dependency leave nothing; leaving with the row; guarded under unjailed. Live (sonnet, approver on): the model wrote a component registering `greet`, the mount prompt showed its source, approved → "mounted greeter: greeter active"; the next cell's greet(who='bruk') was asked about and returned "hello, bruk".

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The loop builds an approval request as {"name", "input", "runs": tool.runs, **shown(tool, name, input)} (bh-02/plugins/agent-cordis-plugin/src/agent_cordis_plugin/loop.py, both the model's calls and nested), and shown() merges whatever the tool's show(input) returns. A show returning "runs" (or "agent", the sub-agent label TASK-0080.03 added) would override the field the approval rule and the modal read. Every show today is a layer row's host-side code (python's shown_call, extensions' shown_tool_call), so the model can't reach it; this is hardening: take only title, lines and language from a show.

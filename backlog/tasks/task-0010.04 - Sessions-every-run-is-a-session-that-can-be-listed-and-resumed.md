## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Leaving bhh loses the conversation. Each run gets a session directory (outside the project) holding its own layer file, the Claude Code session id or the loop's transcript; --resume continues one.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 `bhh --resume` continues the latest session for this directory, `bhh --resume ID` a given one; the model remembers the earlier conversation
- [x] #2 `bhh sessions` lists this directory's sessions, newest first
- [x] #3 Under --ollama the transcript is written as it grows and read back on resume
- [x] #4 Resuming says plainly that the kernel's namespace did not survive
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
bhh/sessions.py: every interactive run creates `$XDG_STATE_HOME/bhh/sessions/<id>/` (meta.json, session.toml). The session's layer (built as Rows, written with cordis's format_layer) carries all per-run choices: llm.session_file (Claude) or transcript.path (Ollama), the model on llm/completion, kernel:unjailed for --no-jail, and the operator's config. It is the last shipped layer, so the jail denies writes to it and a resume is booting with it again; overrides are used only for `bhh ask`'s prompt/model. CLI: `--resume [ID]` (newest for this directory, or by id/prefix; refuses --ollama on a Claude session and --no-jail on any resume; --model on resume rewrites the layer), prints that the kernel starts empty; `bhh sessions` lists newest first. SDK: ClaudeConfig.session_file; the rows read it through their own effect step (`session_step`, keeping components pure) and pass `resume=`; ClaudeModel records the id from the init SystemMessage or any ResultMessage. agent: `agent:transcript` with config.path is a FileTranscript (JSONL appended per message, read back). Tests: pure layer shapes, state dir listing/find, CLI resume of an Ollama-stack session through a scripted completion ("seen 1" then "seen 2"), refusals. Live: `bhh` told "otter", exit, `bhh --resume` answered "otter" and kept model haiku.
<!-- SECTION:NOTES:END -->

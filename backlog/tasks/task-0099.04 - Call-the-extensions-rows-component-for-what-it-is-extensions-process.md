## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-0005 (TASK-0099.01, accepted): the component extensions:extensions repeats its plugin's word, which the naming rule forbids; TASK-0099.02 and .03 carry no rename of it. It becomes extensions:process: the row owns the extensions process as the python row owns the Python process (watches the directory, loads into it, relays what an extension adds, asks approval, stops it on /release); not loader (cordis's word), not host (the shell's row and key), not watcher (one of three jobs). The function extensions_cordis_plugin.wiring.extensions becomes process and its re-export in __init__.py follows. The row id extensions stays, so /restart extensions and a config override of it keep working. No translation (owner, 2026-10-14: no backwards compatibility): nothing maps the old name; TASK-0099.07 removes the translation machinery. About 10 files by grep: README.md, bh-02/CONTRACTS.md, GLOSSARY.md (the extensions (row) entry reads 'extensions:process, bh-02's handle on the extensions process'), app/README.md, bh-02.toml, the extensions and runner plugins' READMEs, wiring.py, __init__.py, tests/test_extensions_host.py. Nothing the model sees changes. After a pull an installed bh-02 needs the reinstall the app README names.

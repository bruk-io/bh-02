## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
No surveyed harness does this (2026-10-29). The worker compares the namespace before and after an input (a name added, a name bound to another object, a name removed) and the done message carries it; the host tells it before the input's output, after PythonProcess._offered's aside. Each name by type and size (a container's length, a callable's signature), never a repr. The whole list goes with the first input after a REPL restart or a resume. The plan settles the intent's third and fourth open questions: the line's cap, and whether in-place mutation is reported (bindings first).

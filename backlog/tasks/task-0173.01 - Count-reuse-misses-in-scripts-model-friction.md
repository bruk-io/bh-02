## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The baseline for TASK-0173: scripts/model-friction reports, per session, the inputs that redo work an earlier input of the same REPL already kept in a variable. What counts as a miss is decided here (the intent's first open question): candidates are the same program or search run again, a name assigned again from the same expression, and a file read again with no write to it in between. Where the evidence allows, say which cause a miss looks like (a name forgotten, state not trusted, a variable's content unknown). A REPL restart starts a new REPL: work redone after one is not a miss.

## Description

TaskWeaver's practice: its compaction carries a variable list (name, type, description) into the summary. bh-02's /compact leaves the model only its own summary of what the REPL holds. Here the list is read from the Python process at compaction time, never from the model's memory, and told with the first input after /compact or in the summary itself (the plan decides which, and what is said when no Python process is running: the intent's fifth open question). A variable is described by name, type and size; no repr.

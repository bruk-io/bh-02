## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The kernel should run confined by default. A plugin binds `jail` with brig: writes confined to the working directory, no network, and brig's graded report visible.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The kernel runs under brig on darwin, and a write outside the working directory from a cell fails
- [x] #2 The jail's enforcement report is available to the rest of the composition

- [x] #4 A cell cannot write the layer files, a workspace member's source, .venv or .git/hooks (planted attempts fail)

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Spiked brig first (scratchpad/brig_spike.py): scratch_darwin + LISTEN channel + venv python works; wrote inside, PermissionError outside, network URLError; interrupt() -> KeyboardInterrupt; kill() ends the group. Found: wait_ready probes by connect+close, so the worker accepts until a connection speaks.

New member brig-cordis-plugin (the only importer of brig; gate rule `brig-one-adapter`, verified with a planted import). `spec_for` (pure): write_allows = project root(s) + the jail's scratch dir (TMPDIR); write_denies = layer files + host import paths under a writable root (sys.path entries, sys.prefix) + brig's SELF_MODIFY list (.git/hooks, .git/config, CLAUDE.md, AGENTS.md, rc files) + config.deny; read_denies = brig's credential list under $HOME; env scrubbed to an allowlist; one LISTEN channel. `BrigJail` compiles scratch_darwin, launches with SubprocessLauncher, waits for the channel; report() known before start (compiled once in a temp dir). Non-darwin: start refuses and names kernel:unjailed. bhh.bootstrap now mounts a `layers` row (`bhh.bootstrap:layer_files`) binding the watched layer paths; `brig:jail` depends on it. terminal-io's not-terminal names now include sys.path/platform/prefix. Tests: spec as a function; real jailed cells (write inside ok; outside, a layer file, .git/hooks denied; network denied; ~/.ssh unreadable). Control run unjailed: the same cells succeed, so the denials are the jail's.

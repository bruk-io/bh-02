## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Run as root (a Docker container, this one), two brig integration tests fail on the test, not on brig: root's CAP_DAC_OVERRIDE ignores the mode bits they rely on. test_bwrap_fs.py::test_a_read_carve_out_inside_the_workspace_is_refused_and_a_sibling_reads expects 'Permission denied' listing the mode-0000 tmpfs that masks a read-denied directory; root lists it (it is empty, so nothing leaks: DEEPVALUE stays out of stdout). test_probe_runner.py::test_a_failed_control_marks_the_battery_vacuous_not_passed plants a failing control by chmod 0o500 on the workspace; root writes anyway, so the control passes and the battery reads CONSISTENT. Found 2026-10-11 running scripts/check as root under tini: with zombies reaped and NO_PROXY's 6 egress failures aside (TASK-0076), these are the only two left, and they hold scripts/check red for anyone who runs it as root.
<!-- SECTION:DESCRIPTION:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-184 (TASK-0079.05) names a residual: the channel directory <jail_dir>/chan is writable from the jail, so a process can put a symlink at a reserved socket's path (its own or a co-tenant's) pointing at a host socket, and HostRuntime.ready and the embedder's dial follow it on the host. The same held for a per-endpoint directory before. Check before a connect that the endpoint is a socket and not a link (lstat), and say so in the ruling.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The bootstrap awaits the first `done` only, so anything that reloads `llm` (a layer edit, and soon /model and /clear) restarts the mode row and bhh exits as if the session ended. It should follow the mode to its new `done`.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Reloading the llm row mid-session keeps bhh running and the next message is answered
- [x] #2 A mode that stops and does not come back is still reported as stopped early
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
bhh.bootstrap._await_mode now follows the mode across restarts: when the awaited `done` task was itself cancelled, settle, and if a *different* `done` is bound, await that one; if none (or the same), the mode stopped and `_raise_if_stalled("stopped early")` reports it as before (the fragile_model test still passes unchanged). New test: a paced session whose llm row is swapped by a layer edit mid-session keeps running, and the next message is answered by the new model; control run with the old single await fails it. The test's fake input had to keep a line across a cancelled read, as the terminal's does.
<!-- SECTION:NOTES:END -->

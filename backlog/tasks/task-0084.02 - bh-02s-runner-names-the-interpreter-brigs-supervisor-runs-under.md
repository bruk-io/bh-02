## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
brig's bwrap supervisor (TASK-0079.06, decision-190) runs under Bwrap(interpreter=), /usr/bin/python3 by default, and a Spec that does not mount that interpreter is refused at compile. bh-02's runner builds its stack as strict_linux() (runner_cordis_plugin/jail.py, _STACKS), so a Linux host whose system Python is elsewhere, or whose allowlist does not mount /usr, is refused before any program starts. The runner should pass the interpreter it chooses (strict_linux(python=...)), one the jail's read allowlist covers.
<!-- SECTION:DESCRIPTION:END -->

- [x] #2 A host whose system python3 is not at /usr/bin/python3 starts a confined session (observed with an interpreter at another path), and one with no usable interpreter fails with brig's InterpreterNotMounted text surfaced to the person
<!-- AC:END -->

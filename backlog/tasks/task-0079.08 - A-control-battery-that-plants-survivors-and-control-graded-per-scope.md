## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
From TASK-0079.01 (2026-10-12): cgroup v2's cgroup.kill works here (on /sys/fs/cgroup/unified; this host mixes v1 and v2), including on setsid() and SIGTERM-ignoring members, but an unprivileged user can use it only in a subtree root delegated (no systemd here); so a cgroup.kill fallback belongs to the host-side runtime. A --as-pid-1 supervisor ignores SIGTERM, SIGKILL and SIGSTOP from inside the jail; from the host SIGSTOP stops it and SIGKILL ends it and everything in its namespace, so a stopped supervisor can be planted without privileges.

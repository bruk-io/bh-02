## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner's pick (2026-10-15) from the TUI inventory: the composer has no prompt history, so a prompt sent a minute ago has to be typed again. In memory for the run; keeping history across runs is carried forward (where it would be stored is a decision of its own).

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 With the slash list closed, Up on the composer's first line recalls the previous line sent this run (a prompt, a /command or a ! line) and Down on its last line goes forward; past the newest, Down gives back the draft that was being typed
- [x] #2 Editing a recalled line and sending it sends the edit and adds it to the history; the history is never changed in place
- [ ] #3 Must not break: tui:ui depends on nothing but its config; nothing blocks the event loop; the slash list, the palette, the question and approval screens and Ctrl-C behave as before except where this task says; a Pilot test for each key or view; scripts/check passes
